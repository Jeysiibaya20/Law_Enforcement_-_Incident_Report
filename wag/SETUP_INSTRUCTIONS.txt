🚀 HOW TO DEPLOY
=================

STEP 1: RUN DATABASE MIGRATION
────────────────────────────────
1. Open phpMyAdmin or MySQL client

3. Go to SQL tab
4. Copy entire contents of: database2/nlp_workflow_migration.sql
5. Paste into SQL editor
6. Click Execute

Expected result: "Query successful" with multiple tables/indexes created

STEP 2: VERIFY FILES IN PLACE
──────────────────────────────
Check these files exist:
✓ modules/NaturalLanguageProcessor.php
✓ modules/IncidentWorkflowManager.php  
✓ modules/NotificationSystem.php
✓ modules/ReviewRequestSystem.php
✓ modules/Incident_report.php (updated)

STEP 3: TEST SYSTEM
───────────────────
1. Open your application
2. Go to: Incident Logging & Classification
3. Click: "Report Incident"
4. Fill form with test data
5. Submit incident
6. Expected: Success message with case number
7. Expected: NLP analysis shows in details modal

STEP 4: VERIFY COMPONENTS
──────────────────────────
Check in incident details:
✓ 🤖 AI ANALYSIS RESULTS section
✓ Threat Level badge
✓ Severity Score display
✓ Confidence percentage
✓ Emotions detected
✓ Sentiment analysis

If not visible, check browser console for errors.

STEP 5: VERIFY NOTIFICATIONS
────────────────────────────
1. Check notifications table has entries:
   SELECT COUNT(*) FROM notifications;
2. Should show > 0
3. Verify user_id matches current users

STEP 6: VERIFY WORKFLOW EVENTS
──────────────────────────────
1. Check workflow_events table:
   SELECT * FROM workflow_events ORDER BY created_at DESC LIMIT 5;
2. Should show incident creation events
3. Verify performed_by is logged

STEP 7: OPTIONAL - CONFIGURE EMAIL
──────────────────────────────────
Edit config/mail_env.php:
- Set SMTP_HOST
- Set SMTP_PORT
- Set SMTP_USER
- Set SMTP_PASS
- Set SMTP_SECURE

Then email alerts will send on critical cases.

STEP 8: LOAD SAMPLE DATA (OPTIONAL)
───────────────────────────────────
1. Create several test incidents with different narratives
2. Test critical incident: Use words like "emergency", "critical", "severe"
3. Test medium incident: Use words like "complaint", "issue"
4. Observe how NLP classifies each differently

🛠️  TROUBLESHOOTING
==================

Problem: NLP columns not showing
Solution: Run database migration script
         Check: SELECT * FROM incidents LIMIT 1;
         Should show nlp_threat_level, nlp_severity_score, etc.

Problem: "Unknown column" database error
Solution: Migration not executed
         Run: database2/nlp_workflow_migration.sql
         Verify all SQL statements executed

Problem: Notifications not created
Solution: Check notifications table exists
         Run: SELECT COUNT(*) FROM notifications;
         Check user_id is valid: SELECT * FROM signup;

Problem: Officer not auto-assigned
Solution: Check bcpc_officers table has records
         Run: SELECT * FROM bcpc_officers WHERE is_available = 1;
         Verify current_case_load < max_case_load

Problem: Email alerts not working
Solution: Check mail_env.php configuration
         Verify SMTP settings correct
         Check email address in signup table
