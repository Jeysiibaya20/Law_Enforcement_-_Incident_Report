## 🎯 Usage Examples

### Generate Incident Report
```php
$report = new IncidentReportTemplate($pdo);
$report->setDateRange('2024-01-01', '2024-01-31');
$report->setMetadata('Generated By', 'Admin');
echo $report->getSummaryTemplate();
```

### Generate Analytics
```php
$analytics = new AnalyticsEngine($pdo);
$analytics->setDateRange('2024-01-01', '2024-01-31');
$dashboard = $analytics->getDashboardAnalytics();
$insights = $analytics->getInsights();
```

### Generate Case Report
```php
$case_report = new CaseReportGenerator($pdo);
$case_report->getCaseReportData($case_id);
echo $case_report->generateCaseHtml($case_id);
```

### Generate BCPC Report
```php
$bcpc = new BCPCReportGenerator($pdo, '01', '2024');
$bcpc->setBarangay('Barangay Name', 'Municipality', 'Province');
echo $bcpc->generateBCPCHtml();
```

## 📊 Analytics Metrics Explained

### Total Incidents
Count of all incident reports created during the period.

### Critical Cases
Incidents with HIGH threat level or >70 severity score.
Requires immediate attention and resource allocation.

### Assignment Rate
Percentage of cases assigned to officers.
Goal: >80% for effective case management.

### Average Severity
Mean severity score (0-100) across all incidents.
Higher scores indicate more serious incident patterns.

### Active Officers
Number of officers with assigned cases during period.

### Closed Cases
Incidents marked as "Closed" in blotter system.
Indicates case resolution and completion.

## 🎯 Key Performance Indicators (KPIs)

| KPI | Target | Formula |
|-----|--------|---------|
| Assignment Rate | >80% | (Assigned Cases / Total Cases) × 100 |
| Closure Rate | >75% | (Closed Cases / Total Cases) × 100 |
| Response Time | <24 hrs | Avg(Blotter Creation Date - Incident Date) |
| Average Severity | <50/100 | AVG(Severity Scores) |
| Child Case Rate | Monitor | (Child Cases / Total Cases) × 100 |
